# Agoda Hotel API examples (retired)

> **I've retired Agoda Hotel API, so the examples in this repo no longer work.** The repo is archived and kept for reference.
> For hotel rates and availability, use my **[Google Hotels Search Scraper](https://apify.com/johnvc/google-hotels-search-scraper?fpr=9n7kx3)** instead, and start from its example repo, [Apify-Google-Hotels-API](https://github.com/johnisanerd/Apify-Google-Hotels-API).

## Use instead

- **[Google Hotels Search Scraper](https://apify.com/johnvc/google-hotels-search-scraper?fpr=9n7kx3)**: hotel prices, ratings, amenities, property details and images from Google Hotels, with filters, vacation rentals and multi-page results. Example repo: [Apify-Google-Hotels-API](https://github.com/johnisanerd/Apify-Google-Hotels-API).
- **[Google Flights API](https://apify.com/johnvc/Google-Flights-Data-Scraper-Flight-and-Price-Search?fpr=9n7kx3)**: fares for one-way, round-trip and multi-city flights, if you're pricing the whole trip. Example repo: [Apify-Google-Flights-API](https://github.com/johnisanerd/Apify-Google-Flights-API).

## Most used

![YouTube, LinkedIn, Google Flights and Google Jobs](https://raw.githubusercontent.com/johnisanerd/ApifyPublicData/main/assets/icons/most-used.png)

- **[YouTube](https://apify.com/johnvc/youtubetranscripts?fpr=9n7kx3)**: transcripts and subtitles for any video, plus [downloads](https://apify.com/johnvc/youtube-download-api?fpr=9n7kx3) and [Shorts](https://apify.com/johnvc/youtube-shorts-api?fpr=9n7kx3)
- **[LinkedIn](https://apify.com/johnvc/linkedin-people-search-api?fpr=9n7kx3)**: [people](https://apify.com/johnvc/linkedin-people-search-api?fpr=9n7kx3), [profiles](https://apify.com/johnvc/linkedin-profile-api?fpr=9n7kx3), [companies](https://apify.com/johnvc/linkedin-company-api?fpr=9n7kx3), [employees](https://apify.com/johnvc/linkedin-company-employees-api?fpr=9n7kx3) and [jobs](https://apify.com/johnvc/linkedin-job-search-scraper?fpr=9n7kx3), with no login or cookies
- **[Google Flights](https://apify.com/johnvc/google-flights-data-scraper-flight-and-price-search?fpr=9n7kx3)**: fares, routes and booking options for any search
- **[Google Jobs](https://apify.com/johnvc/google-jobs-scraper?fpr=9n7kx3)**: listings with salaries and apply links, or [pay per job](https://apify.com/johnvc/google-jobs-scraper---pay-per-result?fpr=9n7kx3)

Same deal as everything else I build: clean JSON, pay per result, no monthly rental. All are MCP-ready, so Claude, Cursor and ChatGPT can call them as tools.

Everything is catalogued at [AlphaOSINT](https://alphaosint.com/?src=apify-retired), searchable by entity, signal or field name.
